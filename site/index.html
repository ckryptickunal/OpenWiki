Turn YouTube, blogs and essays into a linked Markdown wiki

OpenWiki is a command-line tool that pulls transcripts from YouTube videos, playlists and channels, plus articles from any blog, and has an LLM organize them into an Obsidian-compatible knowledge base: source pages, people, companies and topics, all cross-linked. A second brain made of plain files you own.

How it works

From a list of sources to a wiki you can browse, search and feed to an LLM

Every stage writes plain files to disk, so you can inspect, edit or re-run any step on its own.

  1. Collect

    List YouTube channels, playlists, videos and essay sites in sources.json, or add them one at a time from the CLI.

    • YouTube
    • Playlists
    • Channels
    • Blogs
    • .txt / .md

  2. Extract

    Captions come from youtube-transcript-api; articles come from any index page or single URL. Each source becomes a .txt file with a metadata header.

    • .txt + metadata header

  3. Ingest

    An LLM reads each file and extracts a summary, the people, companies and products it mentions, and the topics it covers. Or feed it precomputed JSON.

    • Gemini
    • OpenAI-compatible
    • Local

  4. Wiki & lint

    Markdown pages with YAML frontmatter, [[wikilinks]] and backlinks. lint catches broken links, missing frontmatter and orphan pages, then rebuilds the index.

    • sources/
    • entities/
    • topics/
    • index.md

Features

Built for knowledge bases that keep growing

Videos, playlists and whole channels

Point it at one video, a course playlist, or a creator's entire channel. Captions are saved as searchable text.

Blogs, essays and your own notes

Scrape every post from a blog's index page, grab a single article, or import local .txt and .md files.

Linked like a real wiki

People, companies, products and topics get their own pages, with [[wikilinks]] and backlinks to every source that mentions them.

Obsidian-compatible

Open the folder as a vault and graph view, backlinks and search just work. It's plain Markdown, so any editor works too.

Incremental and idempotent

Re-run anytime. Downloaded videos and essays are skipped, ingest dedupes by file time, and caption-less videos are remembered.

Bring your own LLM

Use Google Gemini or any OpenAI-compatible API, including local Ollama or LM Studio for fully offline ingest.

Lint keeps it healthy

openwiki lint finds broken links, missing frontmatter and orphan pages, and --fix-index rebuilds index.md.

Plain files, no lock-in

No database, no server, no account. Raw text and Markdown on disk, ready for git, grep, or a RAG pipeline.

Quickstart

Your first wiki in four commands

Needs Python 3.10+. Set YOUTUBE_API_KEY for channel discovery and an LLM key (or a local model) for ingest.

1. Install and create a wiki

pip install "git+https://github.com/ckryptickunal/OpenWiki.git"
openwiki init --root my-wiki

2. Add a source

openwiki youtube https://www.youtube.com/watch?v=VIDEO_ID --folder Talks

3. Build the wiki with an LLM

openwiki ingest --all

4. Check links and rebuild the index

openwiki lint --fix-index

More sources

# A whole channel (needs YOUTUBE_API_KEY)
openwiki youtube --channel https://www.youtube.com/@handle --folder "Channel"

# A playlist or course
openwiki youtube --playlist https://www.youtube.com/playlist?list=... --folder Course

# A blog post or essay
openwiki essay --url https://example.com/post --folder Essays

# Your own notes
openwiki text notes.md --folder Notes

# Pull every channel and essay site in sources.json, then ingest
openwiki sync

FAQ

Frequently asked questions

How do I turn a YouTube channel into notes?

Install OpenWiki, set a YOUTUBE_API_KEY, and run openwiki youtube --channel https://www.youtube.com/@handle --folder "Channel". It downloads the captions of every video as plain text files. Then run openwiki ingest --all to turn them into linked Markdown pages for sources, people, companies and topics.

Can I turn a YouTube playlist or online course into study notes?

Yes. Run openwiki youtube --playlist with the playlist URL and a folder name, then openwiki ingest --all. Each lecture becomes a source page, and recurring concepts become topic pages linked back to every lecture that mentions them.

Does it work without an API key?

Partly. Downloading captions for a single video, fetching essays and importing local notes need no YouTube key, although video titles and channel names are only filled in when a YOUTUBE_API_KEY is set. Discovering all videos in a channel needs the key. Ingest needs an LLM, but that can be a local model through Ollama or LM Studio, or you can pass precomputed JSON instead.

Can I run it fully offline?

The ingest step can run fully offline by pointing OpenWiki at a local OpenAI-compatible server such as Ollama or LM Studio. Fetching captions and articles needs the internet, but once your text files are on disk, building and linting the wiki can happen entirely on your machine.

Is it compatible with Obsidian?

Yes. The wiki is plain Markdown with YAML frontmatter and Obsidian-style [[wikilinks]], and entity and topic pages keep backlinks to their sources. Open the wiki folder as an Obsidian vault and the graph view, backlinks and search work immediately.

Which LLMs are supported?

Google Gemini, or any OpenAI-compatible API: OpenAI, OpenRouter, Groq, and local servers such as Ollama and LM Studio. You can also skip the LLM call entirely and ingest a precomputed JSON analysis.

What does it cost?

OpenWiki is free and open source under the MIT license. The only possible cost is whatever your chosen LLM provider charges for ingest; a local model through Ollama or LM Studio costs nothing beyond your own hardware.

What happens when I run it again on the same sources?

Nothing is duplicated. Already-downloaded videos and essays are skipped, ingest dedupes by file modification time, and videos without captions are remembered and skipped. That makes openwiki sync safe to run on a schedule.
