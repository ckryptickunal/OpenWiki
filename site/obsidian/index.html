Obsidian vault

Frontmatter, [[wikilinks]] and backlinks

  • docs: page format
  • OpenWiki on GitHub

Open the wiki/ folder as a vault and it just works. Every page has YAML frontmatter (type, title, url, channel, published date, tags) and links with [[folder/page|Title]], so backlinks, tags and the graph view light up straight away.

Because it is plain Markdown on disk, the same folder works in VS Code, iA Writer, Logseq or a static-site generator, and it makes clean input for a RAG pipeline or a long-context model.

Names in any script

Page names keep non-Latin scripts, so a person named in Hindi or Chinese gets their own page instead of colliding with everyone else.
