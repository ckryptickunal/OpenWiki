Meeting notes, research logs, exported highlights and old blog drafts belong in the same knowledge base as the videos and essays that inspired them.

$ openwiki text meeting-notes.md research/*.txt --folder Notes

The title comes from the first # heading in Markdown, the page title in HTML, or the file name. Each file gets the same header as every other source, so ingest treats them all alike.
